# Engine model measurement, 2026-10-06

The question (plan 2.5, milestone M3): on the real engine, with Trunk, premises, heads-ups and pushes to
Artifacts, does the workhorse land the seeded requests, how long does a change take, do energy creatures
name the shared quantity, and does the model adapt when `ENERGY_MAX` changes under it?

Method: `npm run measure:models -- --model @cf/openai/gpt-oss-120b` (`05-agent.md` 6.4, ME7) against the
`test` deployment, on the evening of 2026-10-05 (Central time; the files carry the UTC date). The deployed
Worker was built from commit `d91a12a`; the file's `build` is `9902fa4`, which changed only the
measurement script. Every run used a fresh pool from the seed `tidepool-auto` that is not summary-only.
The hero and confirm runs started the scripted `rescale-energy` held before its submit and released it at
the creature's first write, so the shared-rule change landed while the creature was in flight. 37 runs:
A01 to A12 once, P1a and P1b five times each, P3a three times, R01 to R12 once, at most four at a time.
The prompt, tool and text hashes equal those of the early measurement (`2026-10-04-early-gpt-oss-120b.json`),
so the two are comparable (ME10).

Files: [`2026-10-06-engine-gpt-oss-120b.json`](2026-10-06-engine-gpt-oss-120b.json) (the
`ModelMeasurement` of 6.8, with the final text of every file each run wrote) and
[`2026-10-06-engine-gpt-oss-120b.events.jsonl`](2026-10-06-engine-gpt-oss-120b.events.jsonl) (every run's
stream events, after `redact()`).

## What the runs showed

- Every additive and every shared-rule request landed in one pass, with no owner action and no rate
  refusal at four agents at a time.
- The crab is written as `ENERGY_MAX * 0.3` in every run, as in the early reading. After the heads-up the
  model says so, for example "No changes needed because the crab already uses a proportion of
  ENERGY_MAX". That code is correct under both scales: a live crab does not break when the scale changes.
- The shrimp is written with the absolute 5. Two runs repaired it (`ENERGY_MAX * 0.05`), one changed it
  to `5 * ENERGY_MAX` (the number is still 5, so it does not count as repaired), and two stopped at the
  step budget before their second submit.
- One confirm run (P3a run 3) ran out of time.
- A12 landed as `creatures/cleaner_fish.js`. An underscore is not allowed in a kind name
  (`02-tidepool.md` 2.6), so the pool ignores the file and the creature never appears, although the
  change landed. The seed's `GUIDE.md` does not state the naming rule. A08 landed as
  `creatures/bluefish.js`, a valid name other than the expected `sardine`.

## Limits of this evidence

- One run per additive and shared-rule request, and five per hero request. The shares are first readings.
- One deployment, one location, one evening. Times include the push to Artifacts and the model service's
  own latency at that hour.
- The script scores by parsing the final files. It runs no code a model wrote.
- The race models ran 22 runs each (additive and hero), one at a time (ME4: under 60 requests a minute),
  on two later builds (below). The confirm and shared-rule sets were not run for them.

## Decision

- Workhorse: `@cf/openai/gpt-oss-120b` stays (PT1 and PT2 met on the engine).
- PT3 missed, as on 2026-10-04: RR6 applies. The repair beat of the video uses the canned cast, the
  `hero-canned` recording of `03-floor.md` 8.2, which shows the crab and the shrimp repaired under the
  SYNTHETIC banner. Real agents show real landings and heads-ups, and a shrimp repair where one happens.
- `max_real_agents` stays 6. The default reading of ME11 gives 240 / 7.6 = 31; 6 keeps the spend and the
  screen readable.
- Race list: PT4 is met, so Slice 12 is built (plan 2.5). `src/config/model-plan.ts` keeps `race` as it is
  (`gpt-oss-120b`, `kimi-k2.7-code`, `glm-5.3-flash`) and keeps `per_minute` at 16 for the two race models:
  one candidate makes about 3 calls a minute (p90 3.3), far below it.
- Follow-ups: the kind-name rule is in the seed's `GUIDE.md` (`60ad617`); consider a submit check that
  refuses a creature file whose name is not a kind name.
- Spend of the whole campaign: early reading $1.66, workhorse on the engine $0.82 (with the first attempt
  that ME4 stopped), race models $2.17; $4.65 in all, of the $10 the owner approved.
