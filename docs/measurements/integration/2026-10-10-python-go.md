## Choices where the plan was silent

1. **One installed parser, not a pool option.** The parse sites (`analyse`, `entityAt`, search, `write`,
   `replace`) take a `LanguageSet`, not a pool. The parser is a per-isolate resource, so core holds one
   installed function (`setSyntaxParser`). Without one, a Python or Go file fails to parse and is opaque, so a
   shell that forgot to install it fails its tests (the workerd test of step 3 would).
2. **LG8 refined.** In tree-sitter-python a `string_content` with an escape sequence has the escape as its only
   child: the rest of its text is in no leaf, so `"a\nb"` and `"c\nd"` would hash equal. LG8 now also keeps the
   `text` of a node whose children leave non-whitespace text uncovered, and of every Python `string_content`
   with children. Tested: `LG8: the text inside a string with an escape sequence is part of the form`.
3. **Python import entities refer to what they import**, as a JavaScript import does (6.2): `from m import n`
   refers to `m#n` (or to the submodule), `import m` to the module.
4. **Python uses:** the name after a dot and a keyword argument's name are not uses. A module used as `a.x` is
   referred to through `x`, not also as a whole. `import a.b` binds both `a` and `a.b`. `from m import *`
   binds nothing that LG9 can follow.
5. **Go:** import entities refer to nothing (a package is a directory of files, and uses carry the references).
   Imports with alias `_` or `.` bind no name. A method is referred to only through a package-qualified
   selector, as LG9 says; `v.M()` inside a package is caught by the extra file premise instead. An imported
   directory's package name comes from its files that are not `_test.go`.
6. **Go grouped specs:** each `const` or `var` entity's node is its own spec, so a change to another spec of the
   group does not change it. Every `const` spec carries its index in the group (`iota`); a spec without a value
   also carries the repeated type and value. A spec that binds several names (`D, E = 1, 2`) gives each name
   the same node.
7. **Arity:** Python's `*` and `/` separators are not parameters. Signatures write `*args`, `**kw`, Go's
   `...name`, and `_` for an unnamed Go parameter.
8. **The extra premise** follows entity premises that have `read`. It is in the `read` tool's `premises` list.
9. **F5 for a file turning opaque** is tested on `classify` directly: `write` and `replace` refuse Python and Go
   that does not parse (LG1), so no tool can make one opaque.
10. **The Phase 0 test** builds its own probe Worker with `wrangler deploy --dry-run` and runs it in Miniflare,
    so it exercises wrangler's `.wasm` bundling without a test route in production code.
